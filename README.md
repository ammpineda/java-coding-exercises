# My Java Playground 🚀

A personal training ground for Java — one (or more) small programs a week, each one digging into a different language feature, data structure, or algorithm.

The plan is simple: **stay consistent, stay curious, and build a library of solved problems I can look back on.**

## 🎯 Goals

- Practice core and advanced Java concepts through real, working code
- Build muscle memory for algorithmic thinking and problem decomposition
- Create a searchable archive of solutions for future reference
- Track progress over time — more exercises, cleaner code, better complexity
